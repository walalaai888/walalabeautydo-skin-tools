# walalabeautydo-skin-tools

IG 留言贈送工具包：35+ 皮膚反應型快速自測（可部署到 Vercel）

## 本機開發（可選）
1. 安裝 Node.js 18+
2. 在專案目錄執行：
   - `npm install`
   - `npm run dev`
3. 打開 http://localhost:3000

## 部署到 Vercel（推薦）
1. 將整個專案上載到 GitHub repo（例如：walalabeautydo-skin-tools）
2. 去 Vercel Dashboard → New Project → 選該 repo → Deploy
3. 部署完成後拎到一條網址，放入 IG 自動回覆即可
